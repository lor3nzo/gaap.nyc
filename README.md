# Is Your Finance Team Ready for AI?

**Live at [gaap.nyc](https://gaap.nyc)**

A 3-minute diagnostic tool for founders and CEOs. 10 questions. A scored assessment. A brutally honest answer.

## What It Does

Evaluates a company's finance function across 10 dimensions: close process, AP automation, technical depth, cash visibility, forecasting, data infrastructure, reporting, AI adoption, scalability, and strategic role.

Outputs a score (10–30) and classifies the organization into one of three tiers:

| Tier | Score | What It Means |
|------|-------|---------------|
| **Legacy** | 10–16 | Operating like it's 2015. Manual everything. Stale data driving every decision. |
| **Transitional** | 17–23 | Some modernization, but stuck in the dangerous middle. Tools without transformation. |
| **AI-Ready** | 24–30 | Finance as competitive advantage. Real-time, automated, and strategic. Fewer than 5% of companies. |

Results include a gap analysis flagging critical and moderate weaknesses by category.

## Why I Built It

Most finance teams are a decade behind the companies they serve. Founders know something is wrong but can't articulate what. This tool gives them the vocabulary and the score to act on it.

I'm one of maybe 100 finance professionals in the country who can both close the books in 5 days AND write the code to automate the process. This app is proof of that.

## Tech Stack

Single-file React application. Zero build step. Zero dependencies beyond React 18 via CDN.

- React 18 (CDN)
- Babel standalone (in-browser JSX)
- Google Fonts (Playfair Display, Source Serif 4)
- Deployed as static HTML on Netlify

No framework. No bundler. No node_modules. One file. Ship it.
